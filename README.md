# ML-персонализация удержания клиентов ММБ

Проект курса **Machine Learning System Design**. Подробности в дизайн-документе: [docs/ml_system_design_doc.md](docs/ml_system_design_doc.md).

## О чём проект

Альфа-Банк теряет клиентов ММБ, то есть ИП и ООО с годовой выручкой до 500 млн руб. Сейчас удержание устроено однообразно: всем уходящим клиентам предлагают примерно одно и то же, а менеджеры сами ищут, что им сказать.

Мы строим систему, которая по каждому клиенту из группы риска делает три вещи:

1. **Определяет вероятную причину оттока.** Например, тарифы и комиссии, качество сервиса, переход к конкуренту или изменения в бизнесе клиента.
2. **Подбирает топ-3 инструмента удержания.** Это скидка, смена тарифа, персональный менеджер, продуктовое предложение и т.п. Инструменты упорядочены по ожидаемому эффекту для этого клиента.
3. **Генерирует персональные аргументы.** Для голосового канала это скрипт для менеджера или робота, для цифрового — пуш, письмо или сообщение в приложении.

## Зачем

Если предложение бьёт в настоящую причину ухода, клиент остаётся чаще, а банк меньше тратит на удержание. Менеджеры тратят меньше времени на подготовку к звонку, а голосовой и цифровой каналы говорят с клиентом согласованно.

## Как решаем

- **Данные.** Транзакции, обороты, обращения в поддержку, тарифы и продукты клиента, история прошлых кампаний удержания.
- **Причина оттока.** Многоклассовая классификация на табличных признаках (градиентный бустинг). Если размеченных причин мало, берём слабую разметку по обращениям и CRM.
- **Ранжирование инструментов.** Сначала правила и пропенсити-модели, затем uplift-оценка эффекта каждого инструмента по итогам прошлых кампаний.
- **Аргументы.** LLM во внутреннем контуре банка. На вход подаём профиль клиента, причину и выбранные инструменты, генерируем текст по шаблону канала и прогоняем через проверки на соответствие требованиям.
- **Оценка.** Офлайн: качество классификации и ранжирования, асессорская оценка текстов. Онлайн: A/B-тест, где смотрим на долю удержанных клиентов против текущего процесса.

Начинаем с PoC на батчевом скоринге, генерация аргументов тоже идёт батчем. Онлайн-режим рассматриваем после PoC.
