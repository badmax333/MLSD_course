# BRD: тестирование выдачи умного поиска

> Документ заказчика (Альфа-Банк), перенесён в Markdown из [brd.docx](brd.docx) без изменений текста.

**Задача коротко.** Клиент банка вводит запрос в поиске в «Альфа-онлайн» и «Альфа-Мобайл», получает список фич. Нужно быть уверенными, что по частым запросам приходят нужные фичи и стоят высоко. Сейчас это смотрят люди, вручную. Нужен инструмент, который собирает выдачу, оценивает ее, считает метрики и подсвечивает просадки

## 1. Проблема бизнеса

Клиент сразу видит только первые три результата, остальные открываются при раскрытии списка. Самые релевантные фичи должны попадать в топ-3. Контроль этого сейчас ручной и неполный:

- **Все проверить руками не хватает ресурсов.** Кейсов много, смотрят выборочно, часть не проверяется совсем
- **Просадки замечают не сразу**, когда добавляют новые фичи, классификатор может деградировать на старых, и нужная фича съезжает ниже в списке

## 2. Для кого

Целевой пользователь: Команда поиска - Получает подсветку просадок и решает, на что обратить внимание

## 3. Цель и критерий успеха

**Цель:** забрать часть ручной разметки интентов

**Критерий успеха:** доля совпадений с ручной разметкой

## 5. Требования

| **№** | **Требование** |
| --- | --- |
| BR-1 | Подсвечивать запросы, которые просели, в том числе когда нужная фича съехала ниже |
| BR-2 | Собирать выдачу по каждому запросу с учетом платформы и версии. Главное - верхние 3 позиции |
| BR-3 | Видин флоу работы агента. Можно посмотреть по шагам и оценить логику |
| BR-4 | По каждой выдаче дается вердикт с объяснением. Ground truth - разметка |

## 0. Глоссарий

| **Термин** | **Определение** |
| --- | --- |
| Фича | Функция или продукт банка в приложении: кредит наличными, заправки, переводы |
| Выдача | Упорядоченный список фич, который пришел в ответ на запрос |
| Интент | Цель клиента, за которой стоит группа запросов: например, вклады |
| Топ-3 | Результаты, которые клиент видит без раскрытия списка |
| Точка | Один размеченный пример: запрос, выдача, вердикт, объяснение |
| Эталон, ground truth | Разметка, которую считаем правдой и с которой сравниваем pipeline |
| R3 | Сколько из топ-3 релевантных |
| CTR3 | На что из топ-3 кликнули и насколько это правильно |
| DCG, NDCG | На какой позиции выдаются самые релевантные результаты |
| Классификатор | Модель, которая подбирает фичи к запросу |
| Фичтогл | Переключатель, который включает фичу не всем клиентам |
| Диплинк | Ссылка, которая сразу открывает нужный экран приложения |
| Тестовый стенд | Тестовая среда банка |
| AlfaGen | Внутренняя платформа банка с языковыми моделями |
